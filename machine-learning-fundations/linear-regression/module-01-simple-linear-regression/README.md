# Module 1 — Simple Linear Regression

This is the first step of my journey into Linear Regression.

In this module, I started with the simplest case: **one input variable and one target variable**. I focused on understanding what the model is doing mathematically before implementing it in Python.

## What I studied

* Linear Regression
* The linear model
* Parameters and predictions
* Residuals
* Ordinary Least Squares (OLS)
* Sum of Squared Errors (SSE)
* Analytical solution
* Basic implementation with NumPy

## My approach

I first worked through the mathematics by hand and then translated the ideas into Python.

The goal was not just to make the model work, but to understand where the equations come from and what they mean.
