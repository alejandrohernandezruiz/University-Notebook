# 🐍 Python Vanilla Course

## Overview

This folder contains a comprehensive review of Python fundamentals and intermediate concepts, developed as part of my personal learning journey in programming, data science, and machine learning.

The main objective of this course is to build a solid understanding of Python before moving further into more advanced topics and libraries.

Although I have already worked with NumPy, Pandas, and the fundamentals of Machine Learning, I decided to take a step back and reinforce my Python foundations. I believe that understanding the language itself, rather than simply learning how to use external libraries, is essential for writing better code, understanding how these libraries work internally, and developing stronger programming skills.

This course is entirely self-taught and developed by me, using Jupyter Notebooks to organize explanations, practical examples, exercises, and personal notes.

It is designed to be a structured learning resource that I can revisit and improve over time.

## 📚 Course Contents

### 01. Fundamentals and Control Flow
- Data types, mutability, and object references.
- Conditional statements and the Walrus Operator (`:=`).
- Efficient iteration with `enumerate()` and `zip()`.
- Python loops vs. NumPy vectorization.

### 02. Data Structures and Comprehensions
- Lists, tuples, dictionaries, and sets.
- Slicing, unpacking, and collection methods.
- Lookup complexity and set operations.
- List, dictionary, and set comprehensions.
- Python data structures vs. NumPy arrays and Pandas DataFrames.

### 03. Functions, Scope, and Functional Programming
- Function arguments, `*args`, `**kwargs`, and Type Hinting.
- Variable scope and the LEGB rule.
- Lambda functions, `map()`, `filter()`, and `sorted()`.
- Python functions vs. Pandas `apply()` and `map()`.

### 04. Intermediate Python and Resource Management
- Exception handling (`try`, `except`, `else`, `finally`).
- File handling and context managers (`with`).
- JSON and CSV processing.
- Iterators and generators (`yield`).
- Python CSV processing vs. Pandas `read_csv()`.

### 05. Object-Oriented Programming and Architecture
- Classes, objects, constructors, and encapsulation.
- Instance and class attributes.
- Dunder (magic) methods and operator overloading.
- Decorators, `@property`, and `@dataclass`.
- Understanding the object-oriented foundations of NumPy and Pandas.
