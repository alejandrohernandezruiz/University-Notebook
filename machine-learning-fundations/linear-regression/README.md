# 📐 Linear Regression

This folder contains a step-by-step study of **linear regression**, developed from mathematical foundations to practical implementation with Python and NumPy.

The goal is to understand not only how linear regression works, but also **why the equations work** and how they can be implemented from scratch.

## 📂 Structure

```text
linear-regression/
├── module-01-simple-linear-regression/
├── module-02-model-evaluation/
├── module-03-multiple-linear-regression/
├── module-04-gradient-descent-algorithm/
└── README.md
```

## 📚 Modules

### Module 01 — Simple Linear Regression

Introduction to linear regression with a single variable.

* Linear model and parameters
* Least Squares method
* Slope and intercept
* Analytical solution
* NumPy implementation

### Module 02 — Model Evaluation

Understanding how to measure and analyse model performance.

* Residuals
* MSE and RMSE
* R²
* Residual analysis
* Model assumptions

### Module 03 — Multiple Linear Regression

Extension to multiple variables using linear algebra.

* Design Matrix
* Matrix formulation
* Orthogonal projection
* Normal Equation
* NumPy implementation

### Module 04 — Gradient Descent Algorithm

Optimization techniques for training models when analytical solutions are costly.

* Optimization theory
* Cost functions
* Partial derivatives
* Learning rate
* Vectorized implementation

## 🎯 Main Objective

The purpose of this module is to build a solid understanding of **linear regression from first principles**, connecting mathematical concepts, linear algebra, and Python implementation.
