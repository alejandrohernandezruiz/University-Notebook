# Module 2 — Model Evaluation and Residuals

After learning how to fit a Linear Regression model, the next question is:

> **How good is the model?**

In this module, I focused on understanding residuals and some of the main metrics used to evaluate a regression model.

## What I studied

* Residuals
* Residual analysis
* Homoscedasticity
* Mean Squared Error (MSE)
* Root Mean Squared Error (RMSE)
* Coefficient of Determination (R²)

## My approach

I wanted to understand what each metric actually tells me about the model instead of treating evaluation metrics as numbers that Python simply gives me.

I also looked at residuals as a way of understanding how the model's predictions differ from the real observations.
