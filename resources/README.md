# 📚 Learning Resources

A curated collection of interactive books, official documentation, and cheat sheets that I actively use as theoretical and practical references.

### 📘 Free Reference Books

* [An Introduction to Statistical Learning (ISLR)](https://statlearning.com) - The fundamental reference for understanding the mathematics behind regression and statistical models.
* [Mathematics for Machine Learning](https://github.io) - An excellent book focused on linear algebra and calculus applied directly to AI.

### 🛠️ Official Documentation (Sources of Truth)

* [NumPy Documentation](https://numpy.org) - An essential reference for vectorized matrix operations.
* [Pandas Documentation](https://pydata.org) - A guide to dataset (`.csv`) manipulation and cleaning.
* [Matplotlib Tutorials](https://matplotlib.org) - For designing residual plots and loss landscapes.

### 📝 Cheat Sheets (Quick Reference Sheets)

* [Python for Data Science Cheat Sheet](https://datacamp.com) - Quick references for Pandas syntax and data manipulation.
* [Linear Algebra Cheat Sheet](https://minireference.com) - Key matrix and vector concepts summarized in just a few pages.
